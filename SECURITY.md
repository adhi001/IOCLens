# Security Policy

## Reporting a vulnerability

Please do not publish exploit details, credentials, or sensitive indicators in a public issue. Contact the repository maintainer privately through GitHub's security advisory feature where available.

## Scope and safe use

IOC-Lens is a research prototype for defensive threat-intelligence analysis. Do not use it as the sole basis for blocking, attribution, or incident-response decisions. Verify findings with independent sources and human review.

Never submit secrets, personal data, customer telemetry, or confidential incident material to an untrusted deployment.
